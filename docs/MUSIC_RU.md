# Музыка: форматы и оптимизация

В `audio/music` лежат 100 треков. В проект они импортируются как **Ogg
Vorbis** — это штатный формат музыки для Godot 4.

---

## 1. Что было и что стало

| | Было | Стало |
|---|---|---|
| Формат | MP3 CBR 320 кбит/с | Ogg Vorbis q5 (~160 кбит/с) |
| Файлов | 100 | 100 |
| Размер | 616 МБ | **266 МБ (43 %)** |
| Частота / каналы | 44.1 кГц, стерео | 44.1 кГц, стерео |
| Громкость | у каждого трека своя | −14 LUFS, пик ≤ −1.5 dBTP |
| Теги и обложки | ID3 + встроенные JPEG | вырезаны |

Почему не оставили MP3:

* Vorbis при том же воспринимаемом качестве занимает примерно вдвое меньше,
  чем 320 кбит/с MP3;
* Godot импортирует OGG с точками лупа (`loop`, `loop_offset`), а лишние
  метаданные и обложки в игре не нужны — они только раздувают экспорт;
* одинаковая громкость треков: при переходе между композициями не нужно
  вручную подкручивать громкость.

Godot хранит музыку в сжатом виде и декодирует её на лету, поэтому память
под трек примерно равна размеру файла. После оптимизации один трек — это
~2–3 МБ вместо ~5–7 МБ.

---

## 2. Где что лежит

```
audio/music/*.ogg              ← то, что видит и импортирует Godot
audio/music/*.ogg.import       ← параметры импорта (loop=false, bpm и т.д.)
source/music_src/*.mp3         ← исходники 320 кбит/с (папка source/ с .gdignore,
                                 Godot её полностью игнорирует)
tools/optimize_music.py        ← перекодирование и генерация .import
```

`source/music_src` добавлен в `.gitignore`: 616 МБ исходников не попадут
в коммит. Если оригиналы не нужны — папку можно удалить, на игру это не
влияет.

## 3. Перекодировать заново или добавить треки

Положить MP3 в `audio/music` и выполнить:

```sh
python3 tools/optimize_music.py                 # всё, что ещё не сконвертировано
python3 tools/optimize_music.py --force         # перекодировать всё заново
python3 tools/optimize_music.py --jobs 8        # быстрее на многоядерном CPU
python3 tools/optimize_music.py --quality 6     # ~192 кбит/с, если нужен запас
python3 tools/optimize_music.py --no-normalize  # не трогать громкость
python3 tools/optimize_music.py --dry-run       # только показать план
python3 tools/optimize_music.py --import-only   # переписать только .import
python3 tools/optimize_music.py --archive-originals source/music_src
```

Скрипт:

1. измеряет громкость трека (`loudnorm`, два прохода);
2. кодирует `libvorbis` в 44.1 кГц / стерео, без тегов и обложек;
3. пишет рядом `.import` с корректным для Godot 4.7 именем импортёра
   (`oggvorbisstr`) и стабильным `uid`;
4. пропускает уже готовые файлы, если OGG новее MP3 (отключается `--force`).

Требуется `ffmpeg` в `PATH`. Качество: `--quality 4` ≈ 128 кбит/с,
`5` ≈ 160 (по умолчанию), `6` ≈ 192, `8` ≈ 256.

## 4. Как использовать в игре

* **Загрузка.** Не делайте `preload` на всю папку: 100 треков — это сотни
  мегабайт. Загружайте по одному:

  ```gdscript
  var stream := load("res://audio/music/CLOUDER - PLACEBO (SPOTISAVER).ogg")
  $Music.stream = stream
  $Music.play()
  ```

  Для меню, где важен мгновенный отклик, подойдёт
  `ResourceLoader.load_threaded_request()` и опрос
  `load_threaded_get_status()`.

* **Плейлист.** Держите один `AudioStreamPlayer` и по сигналу `finished`
  переключайте трек — так в памяти всегда один файл. Для перемешивания
  храните массив путей (его можно собрать один раз в редакторе), а не
  ресурсы.

* **Пауза.** На паузе меню вызывайте `stream_paused = true`, а не
  `stop()`, иначе трек начнётся сначала.

* **Громкость.** Логичнее вынести музыку на отдельную шину: добавьте в
  `default_bus_layout.tres` шину `Music`, направьте её в `Master` и
  регулируйте `AudioServer.set_bus_volume_db(AudioServer.get_bus_index("Music"), db)`.
  Тогда ползунок «музыка» не будет влиять на двигатель.

* **Луп.** Для трека, который должен играть бесконечно, поставьте
  `loop=true` в его `.import` (или запустите скрипт с `--loop`). Для
  плейлиста оставляйте `false` — иначе сигнал `finished` не придёт.

---

## 5. Проверка

Импорт проверен на Godot 4.7.2: OGG превращается в
`.godot/imported/<имя>.ogg-<md5>.oggvorbisstr`, `uid` из `.import`
сохраняется. Если Godot всё же переимпортирует файл, он просто обновит
`.import` и кэш — ассеты при этом не меняются.
