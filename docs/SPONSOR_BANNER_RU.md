# ЖК-щит спонсора

`scenes/props/sponsor_banner.tscn` — рекламный щит, похожий на работающий
ЖК-экран. Он по кругу показывает баннеры из атласа
`textures/4XSponsorBanners.png` (сетка 2×2: APEX DRIFT, GRIPSTONE, KINETIX,
KITSUNE RACING) и плавно растворяет один баннер в другом. Поверх картинки
бегут строки развёртки, экран слегка мерцает, у верхнего края виден блик
стекла. Экраны есть с обеих сторон щита.

## Как устроено

* `Mesh_board` — тёмная рамка, `Mesh_post_l` / `Mesh_post_r` — стойки.
* `Mesh_screen_front` и `Mesh_screen_back` — два экрана (QuadMesh) с общим
  материалом на шейдере `shaders/sponsor_banner.gdshader`.
* Смену баннеров считает **шейдер** по времени, а не скрипт. Щиты из
  библиотеки пропсов запекаются в MultiMesh, а скрипты в нём не работают,
  поэтому так экраны оживают и на трассе, и в гараже, и прямо в редакторе.
  Фаза зависит от положения щита, так что соседние щиты переключаются
  вразнобой.
* Скрипт `scripts/effects/rally_sponsor_banner.gd` (`RallySponsorBanner`)
  только переносит настройки из инспектора в материал экранов. Материал
  помечен `local_to_scene`, поэтому правка одного щита в сцене не меняет
  остальные.

## Настройки (у корня `SponsorBanner`)

| Группа | Параметр | Что делает |
|---|---|---|
| Баннеры | `Banner Atlas` | атлас с картинками одинакового размера |
| | `Atlas Grid` | колонки и строки атласа (по умолчанию 2×2) |
| | `Banner Count` | сколько ячеек занято (слева направо, сверху вниз) |
| | `Cycle Time` | сколько секунд висит один баннер, включая переход (3 с) |
| | `Crossfade Time` | длительность плавного перехода (0,6 с) |
| | `Random Phase` | разносить щиты по времени |
| Стиль ЖК-экрана | `Brightness` | яркость свечения; больше 1 подсвечивает glow |
| | `Scanline Strength` / `Scanline Frequency` | рябь строк и их число |
| | `Flicker Strength` | мерцание яркости |
| | `Gloss Strength` / `Gloss Width` | блик стекла у верхнего края |

## Свои баннеры

Сложите картинки одинакового размера сеткой в один PNG (например, 3×2 для
шести баннеров). Затем укажите его в `Banner Atlas` и выставьте `Atlas Grid` и
`Banner Count`. Исходники нынешних баннеров лежат в `source/`; там есть
`.gdignore`, поэтому Godot их не импортирует. Пропорции ячейки атласа
(сейчас 617×341) лучше держать близкими к экрану 2,9×1,58 м.

Проверка: `godot --headless --path . --script res://tests/sponsor_banner.gd`.
