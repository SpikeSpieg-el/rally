# Экспорт в браузер

В проект добавлен профиль **Web**. Для браузера он использует рендерер
Compatibility (WebGL 2); версия для компьютера сохраняет прежний рендерер.
Профиль не использует потоки, поэтому специальные заголовки COOP/COEP не
обязательны.

1. Установите Godot 4.7 той же версии, что и его export templates (см.
   **Editor → Manage Export Templates**).
2. Откройте `project.godot` и дождитесь завершения импорта ресурсов.
3. Выберите **Project → Export → Web → Export Project** и сохраните как
   `export/web/index.html`. Либо из корня проекта выполните:

   ```sh
   mkdir -p export/web
   godot --headless --editor --path . --import
   godot --headless --path . --export-release Web export/web/index.html
   ```

4. Чтобы проверить локально, запустите из корня проекта:

   ```sh
   python3 -m http.server 8000 --directory export/web
   ```

   Откройте `http://localhost:8000/` в браузере с WebGL 2. Не открывайте
   HTML через `file://`: браузер не сможет корректно загрузить файлы игры.
   Для публикации разместите **все** созданные рядом с `index.html` файлы на
   веб-сервере, раздающем `.wasm` с MIME-типом `application/wasm`.

## GitHub Pages

Workflow `.github/workflows/pages.yml` импортирует проект, собирает Web-версию
на GitHub Actions и публикует её через GitHub Pages при обновлении `main` или
ветки `arena/04a18e75-rally`. Его также можно запустить вручную через Actions.
В настройках репозитория **Settings → Pages → Build and deployment → Source**
необходимо выбрать **GitHub Actions**. Если для окружения `github-pages`
ограничены ветки, разрешите ветку, из которой выполняется публикация.
После успешного выполнения адрес страницы появится в задании Deploy.

Игра рассчитана на клавиатуру/мышь или геймпад; экранных кнопок для телефона
пока нет. Веб-сборка может отличаться по графике и производительности от
настольной версии. Из-за большого объёма игровых ресурсов первая загрузка
может быть долгой. В этой среде экспорт и запуск в браузере не проверены:
Godot и export templates здесь не установлены.
