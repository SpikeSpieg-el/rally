# Новая машина: только кузов и подгонка

Всё делается в редакторе Godot, Python не нужен. Плагин `addons/rally_vehicle_sync`
сам создаёт модель, колёса, ресурс машины, пять пресетов и регистрирует всё в
`data/rally_game_config.tres`.

## 1. Положить кузов

Экспортируйте кузов из Blender в glb и положите файл в папку `cars/`:

```
cars/ferrari_f40.glb
```

Имя файла станет id машины: строчные латинские буквы, цифры и `_`. Пробелы и
дефисы заменяются на `_`. Кириллица и пробелы в имени не сработают.

## 2. Открыть проект в Godot

При открытии проекта и после импорта кузова плагин сам создаёт:

| Что | Где |
| --- | --- |
| модель машины (кузов + колёса) | `scenes/vehicles/<id>_model.tscn` |
| ресурс машины | `data/vehicles/<id>.tres` |
| пять пресетов | `data/setups/<id>/<id>_{stock,gravel,snow,tarmac,gravel_spec}.tres` |
| регистрация | `data/rally_game_config.tres` (машины и пресеты) |

Результат виден в Output: строка `[Машины] создана «...»`. Ошибка — красная строка
с именем машины и причиной. При ошибке созданные файлы этой машины удаляются,
конфиг не меняется.

Если кузов только что положили, Godot сначала импортирует его. Плагин подхватит
файл сам после импорта. Вручную то же самое: меню **Project → Tools → «Rally:
собрать машины из cars/»**.

Уже созданная машина не перезаписывается, поэтому правки в инспекторе не
теряются.

## 3. Подгонка кузова

Откройте `data/vehicles/<id>.tres`, группа **«Кузов из glb (авто)»**:

- `body_length_m` — длина кузова после авто-подгонки (по умолчанию 4.46 м);
- `body_rotate_deg` — поворот вокруг вертикали, `-1` — определить сам;
- `body_scale` — ручной масштаб, `0` — считать по длине;
- `body_offset` — сдвиг кузова (X вбок, Y вверх, Z вперёд);
- `ground_clearance` — зазор низа кузова над землёй;
- `rebuild_model` — включите и сохраните: модель пересоберётся при следующем
  открытии проекта, флаг сбросится сам.

Колёса физики стоят на точках из `scenes/rally_car.tscn`, поэтому кузов
подгоняется именно под них. Если в glb есть узлы `Wheel_FL`, `Wheel_FR`,
`Wheel_RL`, `Wheel_RR`, колёса берутся из модели, а не создаются процедурно.

## 4. Звук и настройки

- Звук мотора: поля **«Звук мотора»** в `data/vehicles/<id>.tres`. По
  умолчанию машина использует звук Lancer (`audio/engine/`).
- Пресеты: `data/setups/<id>/*.tres` — мощность, масса, подвеска, шины.
  Правьте в инспекторе, код не нужен.

## Что проверить после добавления

1. Output без красных строк `[Машины]`.
2. Главное меню → выбор машины: новая машина появилась в списке.
3. Гараж: кузов виден, колёса стоят на месте. Если нет, поправьте
   `body_*` и включите `rebuild_model`.
4. Заезд: кузов на трассе, колёса вращаются.

## Ограничения

- Пыль и кровь на кузове работают по имени кузова из модели. Если кузов не
  виден, проверьте, что в модели задана метка `car_body_mesh` (плагин ставит её
  сам).
- Тормозные огни и фонари пока есть только у Lancer.
- Для первого открытия Godot должен импортировать glb сам: файл `.glb.import`
  создаётся редактором.
