# Обратная связь DualSense

В настройках контроллера можно отдельно включить дорожную вибрацию,
адаптивные триггеры и настроить силу. В заезде сопротивление L2 зависит от
скорости и торможения, R2 — от оборотов и газа. Эффект включается только для
педалей, назначенных на соответствующую ось. Обычная вибрация меняется в
зависимости от оборотов, покрытия, скорости и скольжения; короткие импульсы
переключения передачи и финиша имеют приоритет. На паузе и при выходе из
заезда эффекты снимаются.

**Ограничения:** Godot не предоставляет API адаптивных триггеров и
высокоточной аудиотактильной вибрации DualSense. Здесь дорожная вибрация —
обычная совместимая вибрация через Godot, а не настоящий HD haptics.
Триггеры реализованы через необязательный мост для **Linux, USB и одного
подключённого геймпада** (DualSense или DualSense Edge). Bluetooth, Windows,
macOS и несколько геймпадов пока не поддерживаются для триггеров; обычное
управление и стандартная вибрация остаются доступными. Статус моста виден в
настройках. Физически протестировать силу на устройстве необходимо отдельно.

Для моста нужен Python 3 в PATH и доступ на запись к соответствующему
`/dev/hidraw*`. Например, на Linux с systemd-logind можно установить правило
udev (не запускайте игру от root):

```udev
# /etc/udev/rules.d/70-rally-dualsense.rules
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="054c", ATTRS{idProduct}=="0ce6", TAG+="uaccess"
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="054c", ATTRS{idProduct}=="0df2", TAG+="uaccess"
```

Затем выполните `sudo udevadm control --reload-rules` и переподключите USB.
Проверьте права, если статус показывает ошибку доступа. Другие программы,
управляющие триггерами, могут конфликтовать с игрой. При потере связи с игрой
мост сбрасывает сопротивление через 0,8 секунды, а при нормальном завершении —
сразу. При физическом отключении питания сброс HID, естественно, невозможен.

При экспорте Godot добавьте `tools/dualsense/trigger_bridge.py` в фильтр
не-ресурсных файлов экспорта (например, `*.py`); без него мост будет
недоступен. Для тестов без железа:

```sh
python3 -m unittest discover -s tests -p 'test_dualsense_bridge.py'
godot --headless --path . --script res://tests/driving_feedback.gd
```
