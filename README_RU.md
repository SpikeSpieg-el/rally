# Rally 4.7 — Mitsubishi Lancer Evolution

Рабочий проект для **Godot 4.7.x** (проверялось по API 4.7.2). Всё основное
содержание — трассы, конфигурации машины, погода, рельеф и меню — лежит в
обычных ресурсах `.tres` и сценах `.tscn`, то есть редактируется в инспекторе
Godot без правки кода.

## Что было исправлено для Godot 4.7

0. **Главная причина «проект не работает в 4.7»:** в `scenes/rally_car.tscn`
   три строки `[node name="WheelVisual" ...]` заканчивались лишней кавычкой
   (`unique_id=1697940092"]`). Парсер сцен 4.7 выдавал
   `Parse Error: Parse error. [Resource file res://scenes/rally_car.tscn]`,
   из-за чего не грузилась и `rally_stage.tscn` (она инстанцирует машину),
   а вместе с ней — весь заезд. Строки исправлены. Проект проверен реальным
   движком **Godot 4.7.2** в headless-режиме: меню, все 5 трасс, все
   конфигурации, случайная генерация и 200+ кадров физики — без ошибок.
1. **Удалён закоммиченный кэш `.godot/`** (51 МБ бинарных `shader_cache`,
   `imported/*.ctex`, `uid_cache.bin`, `filesystem_cache10` с Windows-машины).
   Именно такой кэш чаще всего даёт «проект не открывается» на другой версии
   движка. Добавлен `.gitignore`, кэш создаётся заново при первом открытии.
2. **`source/.gdignore`** — исходный `.blend` больше не дёргает импортёр
   Blender при каждом открытии проекта (модель уже встроена в сцены).
3. `project.godot`: убрано `display/window/hdr_output/enable=true` (на обычном
   SDR-мониторе давало чёрный/выцветший экран), явно заданы `forward_plus`,
   `stretch/aspect="expand"`, новая главная сцена и автозагрузка.
4. `ConcavePolygonShape3D`: в 4.7 свойство `faces` переименовано в `data`.
   Генератор теперь вызывает `set_faces()` если он есть и `set("data", ...)`
   в противном случае (`scripts/rally_stage.gd::_set_shape_faces`).
5. `scripts/gevp/vehicle.gd`: строка `if not vehicle_inertia:` — неявное
   приведение `Vector3` к `bool`. Заменено на явный флаг `inertia_initialized`.
6. `scripts/gevp/wheel.gd`: `wrapf(spin * delta, 0.0, TAU)` ломал вращение
   назад; теперь знак сохраняется, а угол ограничен диапазоном `-PI…PI`.
   Добавлена защита от неназначенного `wheel_node`.
7. Все обращения к узлам в новых сценах идут через `get_node_or_null()` —
   отсутствие HUD/окружения больше не роняет заезд.

## Быстрый старт

1. Откройте `project.godot` в Godot 4.7. Дождитесь первого импорта (1–2 минуты:
   движок пересоздаёт `.godot/`).
2. **F5** — запуск. Откроется меню.
3. Выберите режим, трассу, конфигурацию Lancer Evo, при желании задайте сид.
4. **СТАРТ**. ESC — пауза (рестарт / меню / выход), F1–F5 — смена трассы на ходу.

### Управление

| Клавиши | Действие |
|---|---|
| W / S, ↑ / ↓ | газ / тормоз-задний ход |
| A / D, ← / → | руль |
| Space | ручник |
| Q / E | КПП в ручном режиме |
| C | камера: action-3rd → капот → кокпит |
| V | привод AWD → RWD → FWD |
| R | сброс машины на старт |
| F1…F5 | трассы 1…5 (новая генерация) |
| ESC | пауза |
| ЛКМ / СКМ | захват курсора / сброс обзора мышью |

## Где что редактировать в Godot

| Что хотите изменить | Куда идти |
|---|---|
| Список/порядок трасс и конфигураций, заголовок меню, цвет акцента | `data/rally_game_config.tres` → Inspector |
| Название, длина, сид, изгибы, холмы, кочки, деревья, туман, небо, цвета земли и дороги, сцепление | `data/tracks/track_0X_*.tres` |
| Мотор, коробка, привод, масса, подвеска, шины, радиус, цвет кузова, камера | `data/setups/setup_0X_*.tres` |
| Внешний вид меню, кнопки, шрифты | `scenes/main_menu.tscn` |
| HUD, панель паузы, экран финиша, свет, окружение | `scenes/rally_stage.tscn` |
| Модель Lancer Evo, колёса, камеры, фары | `scenes/rally_car.tscn` |
| Вид дороги/грунта в 3D | `shaders/forest_ground.gdshader`, `shaders/mountain_track.gdshader` |
| Эффект скорости | `shaders/speed_fx.gdshader` |
| Набор полей ресурса (добавить новый параметр) | `scripts/data/*.gd` — `@export` переменные |
| Сама генерация (если не хватает параметров) | `scripts/rally_stage.gd` |

**Добавить шестую трассу:** скопируйте любой `.tres` из `data/tracks/`,
поменяйте `id`, `display_name`, параметры и перетащите файл в массив `tracks`
ресурса `data/rally_game_config.tres`. Кнопка в меню появится сама; клавиша
F6 — при желании добавьте action `track_6` в Project Settings → Input Map.

**Добавить конфигурацию машины:** то же с `data/setups/` и массивом
`car_setups`. Никаких `if/elif` в коде — значения читаются из ресурса.

## Пять трасс

| # | Трасса | Покрытие | Особенность |
|---|---|---|---|
| 1 | ЛЕСНОЕ РАЛЛИ | гравий | быстрые дуги, холмы, гребни |
| 2 | ГОРНЫЙ СЕРПАНТИН | укатанный грунт | крутые подъёмы, узкая дорога, скалы |
| 3 | ЛЕС: ПОДВЕСКА | разбитый гравий | диагональные кочки, волны, crest |
| 4 | ПОЛИГОН / СЛАЛОМ | асфальт | ровная плоскость, конусы, замеры |
| 5 | СНЕЖНАЯ ТРАССА | снег/лёд | низкое сцепление, густой туман |

Каждая трасса — это **фиксированный сид**, поэтому результат воспроизводим.
Любую трассу можно сделать случайной, включив в её ресурсе `random_seed`.

## Режим «всегда случайно»

`ВСЕГДА СЛУЧАЙНАЯ КАРТА` в меню (или `force_random_seed = true` у сцены
`scenes/random_stage.tscn`) генерирует **новый сид перед каждым заездом**:
другая форма дороги, другие холмы, кочки, гребни, деревья, камни и ворота.
Параметры берутся из выбранной трассы, поэтому random-лес остаётся лесом,
а random-горы — горами. Синхронизация «картинка = физика» обеспечена тем,
что шейдер земли, визуальная лента дороги и `ConcavePolygonShape3D`
коллизии используют одну и ту же функцию маршрута и высоты.

Текущий сид виден в HUD и на мини-карте меню. Рекорды сохраняются в
`user://rally_records.cfg` отдельно для каждой трассы и сида.

## Что исправлено в колёсах Lancer Evo

| Проблема | Исправление |
|---|---|
| Физический радиус `0.35 м`, у 3D-модели `0.438 м` — колёса тонули в земле | `tire_radius = 0.438` во всех конфигурациях; визуал автоматически масштабируется под радиус из ресурса (`RallyCar.wheel_visual_radius`) |
| Точки подвески на `Y=0.35` — колёса висели на ~13 см ниже арок | raycast-узлы подняты на `Y=0.51 / 0.519` (радиус + статический ход) |
| Корень модели был сдвинут по X на −0.072 — колёса не совпадали с арками | сдвиг убран, колёса стоят симметрично на `X = ±0.99` |
| Тормозные диски были утоплены внутри покрышки | вынесены на внешнюю грань `X = ±0.152`, сохранена правильная ориентация нормали |
| В меши колёс был запечён поворот на 16.3° вокруг оси | `Transform3D` сброшен в единичный; вращение теперь только от GEVP |
| Реверс колёс крутился вперёд из-за `wrapf` | новый расчёт угла в `scripts/gevp/wheel.gd` |
| Длина луча не соответствовала радиусу | `target_position` выставлен в `-(ход + радиус)` |

Формула статики: `высота центра колеса над телом = tire_radius`,
`точка крепления = tire_radius + spring_length × (1 − resting_ratio)`,
`origin кузова над землёй ≈ 0.063 м`. Всё это пересчитывается в
`RallyCar.get_spawn_height_offset()`, поэтому спавн не проваливает машину.

## Структура

```
project.godot            главная сцена = scenes/main_menu.tscn, Autoload RallyGame
data/
  rally_game_config.tres списки трасс/конфигураций, заголовок меню, пути сцен
  tracks/*.tres          5 ресурсов RallyTrackConfig
  setups/*.tres          4 ресурса RallyCarSetup
scenes/
  main_menu.tscn         меню в стиле Colin McRae Rally + мини-карта
  rally_stage.tscn       универсальная сцена заезда (HUD, пауза, финиш)
  rally_car.tscn         Lancer Evo + GEVP, исправленные колёса
  forest_rally.tscn ...  готовые пресеты: F6 на сцене = сразу заезд
  random_stage.tscn      принудительно случайная карта
scripts/
  game_state.gd          Autoload RallyGame, выбор меню, рекорды
  main_menu.gd, stage_preview.gd
  rally_stage.gd         генератор трассы, HUD, таймер, пауза
  rally_car.gd           применение конфигурации, камеры, визуал колёс
  data/*.gd              классы ресурсов (все поля @export)
  gevp/*                 независимая физика GEVP
shaders/                 земля/дорога, полигон, эффект скорости
```
