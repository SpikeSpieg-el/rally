# Rally — Mitsubishi Lancer Evolution (Godot 4.x)

Раллийный спецучасток, который **редактируется прямо в 3D-вьюпорте Godot**:

* **дорога** — кривая узла `Route` (Path3D) в `scenes/rally_stage.tscn`.
  Тяните точки мышью — полотно и земля пересобираются вокруг новой кривой;
* **ассеты** — обычные узлы в `Props` (601 штука: ели, пихты, кусты, валуны,
  щиты). Двигайте, копируйте, удаляйте, ставьте свои — как любые объекты сцены.

```
scenes/rally_stage.tscn              ← ГЛАВНАЯ сцена: дорога + ассеты + машина
scenes/props/*.tscn                  ← библиотека ассетов (ель, пихта, куст, валун, щит)
data/tracks/stage_forest_route.tres  ← та же кривая дороги (редактируется и так)
data/tracks/stage_forest.tres        ← числовые настройки: ширины, рельеф, цвета, небо
data/setups/*.tres                   ← конфигурации машины
scripts/rally_stage.gd               ← сборка мешей земли и полотна (скрипт-инструмент)
scripts/road_network.gd              ← расстояние до дороги / километраж
tools/author_route.py                ← генератор кривой из отрезков (по желанию)
tools/bake_stage_scene.py            ← пересобрать ассеты в сцене (по желанию)
```

## Быстрый старт

1. Открыть `project.godot` в Godot 4.7+ (проект использует формат сцены 4.7).
2. **F5** — меню. Дождаться первого импорта.
3. Выбрать доступную конфигурацию машины → **СТАРТ**.
4. **F6** на `scenes/rally_stage.tscn` — тот же заезд без меню.

### Управление

| Клавиши | Действие |
|---|---|
| W / S, ↑ / ↓ | газ / тормоз-задний ход |
| A / D, ← / → | руль |
| Space | ручник |
| Q / E | КПП в ручном режиме |
| C | камера: action-3rd → капот → кокпит |
| V | привод AWD → RWD → FWD |
| R | вернуть машину на ближайшую точку трассы |
| ESC | пауза |

## Камеры: вид пилота и настройки

Нажмите **C** дважды после старта, чтобы переключиться с камеры сзади через
капот на вид из кабины. Мышь поворачивает обзор, средняя кнопка мыши возвращает
его в центр. В меню паузы **ESC** есть ползунки FOV, движения камеры и
чувствительности мыши; они сохраняются в `user://rally_camera.cfg`. Кнопка
сброса возвращает настройки из сцены. Более подробные параметры доступны в
инспекторе узла `RallyCar`.

Чтобы изменить позицию **и направление** взгляда пилота:

1. Откройте **`scenes/rally_car.tscn`**, выберите `Cameras/CamCockpit`.
2. Двигайте и вращайте именно `CamCockpit`, затем сохраните сцену. В игре
   используется его сохранённая трансформация; при переключении камеры и
   нажатии **R** маркер больше не сбрасывается. На машине +Z — вперёд, +Y — вверх.
3. Для проверки запустите этап и нажмите **C** до надписи «КАБИНА».
   `ActiveCamera` скрипт перемещает сам; редактировать её положение не нужно.

В инспекторе корня `RallyCar` доступны `initial_camera_mode`, `cockpit_fov`,
`hood_fov`, `inside_speed_fov_bonus`, `cockpit_motion_strength` и
`cockpit_roll_degrees`. Установите «Движение камеры» в паузе (или
`cockpit_motion_strength` в инспекторе) в `0`, чтобы отключить инерционное
смещение и наклон камеры: без свободного обзора она будет строго на маркере
даже при ускорении и повороте. Сохранённые ползунки паузы
имеют приоритет над соответствующими значениями инспектора; кнопка сброса в
паузе снова применяет значения сцены. Для камеры сзади есть отдельные
`chase_min_fov` / `chase_max_fov`, а положение задаётся маркером `CamChase`,
пока включён `use_cam_chase_from_scene`.

## Ночной лес: освещение и шейдеры

Этап теперь ночной: луна, звёздное небо, туман, фары с тенями и гравийный
шейдер с колеями. В `data/tracks/stage_forest.tres` можно менять `sun_color`,
`sun_energy`, `sun_pitch/yaw`, `ambient_color/energy`, `exposure`, `fog_color`,
`fog_density` и `star_intensity`. При плохой производительности отключите там
`volumetric_fog` и/или `screen_space_ao`; объёмный туман и SSAO требуют Forward+.
Фары находятся в `BodyCollider/HeadlightL` и `HeadlightR` сцены машины: их
яркость, дальность, угол и тени редактируются как свойства `SpotLight3D`.

`data/tracks/night_environment.tres` задаёт ночной фон предпросмотра в редакторе.
В **игре** параметры окружения заново берутся из ресурса трассы, поэтому
яркость, туман и цвет меняйте в первую очередь в `stage_forest.tres`.
Шейдеры: `shaders/night_sky.gdshader`, `shaders/gravel_road.gdshader` и
`shaders/forest_ground.gdshader`.

## 1. Как устроена трасса

Карта не генерируется «на лету» и не зависит от сида. Есть **осевая линия**
(сплайн из точек) и **функция высоты**, которая достраивает землю вокруг неё:

```
высота = база + (высота_дороги - база) * (1 - t)
```

* `t = 0` на полотне → земля ровно совпадает с дорогой;
* `t = 1` вдали → чистый рельеф;
* между ними — насыпь/выемка, уклон которой не круче
  `embankment_slope_deg`.

Поэтому дорога **не может** пробить рельеф и на ней не бывает «кочек под
большим углом»: и меш полотна, и меш земли, и все ассеты берут высоту из
одной функции.

База рельефа складывается из:

* **регионального уровня** — высота дороги, размытая на десятки метров
  (поэтому дорога всегда лежит в своём рельефе, а не на 30-метровой насыпи);
* **холмов** (`hills_height`, `ridge_height`), которые включаются плавно по
  мере удаления от дороги (`hills_fade_start`, `hills_fade_length`);
* **лимита склонов** (`max_terrain_slope_deg`) — страховка: если где-то
  (например, между «ногами» тесной шпильки) получается стенка, она
  размазывается на несколько ячеек сетки;
* **кювета** (`road_ditch_depth`, сейчас 0.3 м) — земля у самой кромки
  намеренно опущена. Полотно всегда лежит выше земли, а его внешняя кромка
  ложится ровно на меш земли, поэтому между дорогой и рельефом нет ни щели,
  ни «протыкания» даже на косогоре.

### Как редактировать дорогу (в 3D)

1. Открыть `scenes/rally_stage.tscn`.
2. Выбрать в дереве узел **`Route`** (Path3D) → в 3D-вьюпорте появится
   кривая с точками.
3. Тянуть точку мышью — тянется дорога; тянуть за касательные-ручки —
   меняется радиус поворота. Высота точки = высота дороги (подъёмы и спуск
   задаются прямо в 3D).
4. **Отпустить точку и подождать полсекунды — трасса пересобирается сама**
   (земля, полотно, обочины, посадка ассетов). В панели «Вывод» появится
   строка `Трасса пересобрана: 2412 м, точек кривой 39, 4.1 с`.
5. **Ctrl+S** — сохранить сцену. Кривая лежит в отдельном файле
   `data/tracks/stage_forest_route.tres`, поэтому надёжнее
   **Файл → Сохранить всё** (File → Save All): тогда сохранятся и сцена,
   и кривая.

#### Если изменений не видно

| Симптом | Что делать |
|---|---|
| Ничего не пересобирается | в инспекторе узла `RallyStage` нажать кнопку **«Пересобрать трассу»** (группа «Редактор») |
| Кнопки нет | узел `RallyStage` не выбран, либо у сцены потерялся скрипт `scripts/rally_stage.gd` |
| В «Выводе» нет строки «Трасса пересобрана» | снять/поставить галочку `preview_in_editor` у `RallyStage` |
| Дорога в игре старая | вы сохранили сцену, но не кривую → **Файл → Сохранить всё** |
| Трасса собирается долго | увеличить `terrain_cell` до 3.0 или уменьшить `terrain_margin` в `stage_forest.tres` |

Пересборка запускается только когда правка затихла (0.45 с), поэтому во время
перетаскивания точки ничего не подвисает. Полный пересчёт занимает несколько
секунд — это нормально: на каждый пересчёт строятся меш земли, меш полотна,
коллизия и посадка 600 ассетов.

Кривая лежит в общем ресурсе `data/tracks/stage_forest_route.tres`, так что
она же используется мини-картой в меню — правка в 3D сразу видна и там.

Запасной вариант — `tools/author_route.py`: кривая собирается из отрезков
(«прямая/дуга + подъём») в таблице `SEGS`, затем `python3 tools/author_route.py`.

### Скорость и качество

* `terrain_cell` — шаг сетки земли. `2.0` — красиво, `3.0` — грубее и
  быстрее (время сборки карты растёт квадратично).
* `terrain_margin` — сколько метров земли вокруг трассы. Больше — дольше.
* `road_step` — шаг полотна. `1.0–1.5` достаточно.

## 2. Как расставить ассеты (в 3D)

Все ассеты — обычные узлы сцены `scenes/rally_stage.tscn` в узле **`Props`**:

| Что | Файл | Сколько |
|---|---|---|
| ель у дороги | `scenes/props/pine_tree.tscn` (с коллизией ствола) | ~180 |
| дальний лес | `scenes/props/fir_tree.tscn` | ~250 |
| куст | `scenes/props/bush.tscn` | ~50 |
| валун | `scenes/props/boulder.tscn` | ~110 |
| щит | `scenes/props/road_sign.tscn` | 6 |

* **Перетащить из FileSystem** готовую сцену в узел `Props` — станет объектом.
* **Двигать / вращать / масштабировать** — обычными инструментами вьюпорта
  (W/E/R), либо в инспекторе.
* **Поставить на землю** — кнопка **«Посадить ассеты на землю»** в инспекторе
  `RallyStage` (или автоматически при «Пересобрать трассу»).
* **Свои объекты** кладутся в узел `ManualProps` — с ним ничего не происходит,
  кроме той же посадки на землю.

Хотите другую плотность леса — просто выделите группу узлов `Fir_*` и удалите /
скопируйте. Никаких ползунков «сколько деревьев» больше нет.

`tools/bake_stage_scene.py` умеет перегенерировать стандартный набор ассетов
(густой лес вдоль всей трассы) — это удобно, если дорогу сильно перекроили.

## 3. Параметры трассы (`data/tracks/stage_forest.tres`)

| Группа | Поля |
|---|---|
| Описание | `id`, `display_name`, `description`, `surface_name`, `difficulty`, `target_time` |
| Дорога | `road_curve`, `road_half_width`, `road_shoulder`, `road_step`, `road_camber`, `offroad_grip` |
| Рельеф | `terrain_margin`, `terrain_cell`, `terrain_seed`, `hills_height/frequency`, `ridge_height/frequency`, `hills_fade_start/length`, `max_terrain_slope_deg`, `road_ditch_depth`, `detail_height/frequency`, `embankment_slope_deg`, `embankment_min/max_width` |
| Неровности полотна | `bumps_amplitude`, `bumps_wavelength`, `bumps_roughness`, `bumps_cross` (сейчас всё 0 — полотно гладкое) |
| Разметка | `spawn_route_markers`, `spawn_edge_posts`, `spawn_checkpoints`, `checkpoint_interval` |
| Цвета | `ground_color`, `ground_color_2`, `rock_color`, `road_color`, `road_color_2`, `shoulder_color`, `edge_post_color` |
| Небо и свет | `night_mode`, `sky_top_color`, `sky_horizon_color`, `star_intensity`, `sun_color/energy/pitch/yaw`, `ambient_color/energy`, `exposure`, `fog_color/density`, `volumetric_fog`, `screen_space_ao` |
| Сцепление | `grip_scale`, `rolling_resistance_scale` |
| PS1-стиль | `ps1_style`, `flat_shading`, `dither_fog`, `color_banding`, `sky_flat`, `enable_speed_fx` |

**Неровности полотна** (`bumps_*`) — то, что чувствует машина: волны
(«стиральная доска») и мелкая тряска. Сейчас они **выключены** (`0`), потому что
на 5-метровых волнах машину буквально подбрасывало. Если захочется «тряски» —
начните с `bumps_amplitude = 0.04` и `bumps_wavelength = 14`, а не с 0.13/5.5.

Асеты списком (`props` в `.tres`) больше не используются — они живут узлами
в сцене, см. раздел 2.

## 4. Вторая трасса

1. Скопировать `stage_forest.tres` → `stage_my.tres`, поменять `id`,
   `display_name`, цвета, рельеф.
2. Скопировать `stage_forest_route.tres` → `stage_my_route.tres` и
   перетащить новый Curve3D в поле `road_curve`.
3. Добавить ресурс в массив `tracks` в `data/rally_game_config.tres`.
4. Кнопка в меню появится сама.

## 5. Что изменилось относительно старой версии

* Удалена процедурная генерация маршрута (`rally_route.gd`) и «случайные
  трассы» вместе с сидами — вместо них ручная осевая линия.
* Удалены трассы-заготовки `track_01…track_07`, сцены под них, полигон и
  слалом, шейдер плоскостного полигона.
* Дорога и земля больше не считаются «каждый сам по себе»: одна функция
  высоты, поэтому полотно не клипает через рельеф.
* Появились `RoadNetwork` (расстояние/километраж по дороге) и `@tool`-предпросмотр
  трассы в редакторе.
* Ассеты больше не «ползунки в инспекторе»: 601 объект запечён узлами в сцену
  `scenes/rally_stage.tscn`, их двигают прямо в 3D.
* Полотно стало шире (10 м проезжая часть + 2 м обочины), кочки выключены,
  сцепление вне дороги поднято (0.9), кювет мягче (0.3 м), а **R** теперь
  возвращает машину на ближайшую точку трассы, а не на старт.
* Мини-карта в меню рисует ту же кривую, что и заезд.

## 6. Если что-то не так

| Симптом | Причина / лечение |
|---|---|
| В редакторе пусто | нажать «Пересобрать трассу»; проверить, что у узла `Route` есть кривая |
| Дорога «висит» над землёй | слишком большой `embankment_max_width` при маленьком `embankment_slope_deg` |
| Дорога местами «утоплена»/клипает | `road_ditch_depth` должен быть > 0 (0.3); если 0 — вернуть |
| Застрял вне дороги | клавиша **R** ставит машину на ближайшую точку трассы; сцепление вне дороги — `offroad_grip` (0.9) |
| Провалы/стенки между ветками шпильки | сделать «полку» (ровный участок) до и после шпильки, либо уменьшить `max_terrain_slope_deg` |
| Долго грузится | увеличить `terrain_cell` (3.0) и уменьшить `terrain_margin` |
| Машина проваливается на старте | проверить, что у сцены есть узлы `Terrain/TerrainMesh`, `Terrain/TerrainCollider` |
| Нет рекордов | `user://rally_records.cfg`, ключ — `id` трассы |

Документация по машине и подвеске — `RALLY_SETUP_RU.md`.

### Автоматические проверки

После установки Godot 4.7 запустите из папки проекта:

```sh
godot --headless --editor --path . --quit  # первоначальный импорт ресурсов
godot --headless --path . --fixed-fps 120 --script res://tests/rally_regression.gd
godot --headless --path . --fixed-fps 120 --script res://tests/stage_smoke.gd
godot --headless --path . --fixed-fps 120 --script res://tests/handling_benchmark.gd
```

Проверки без окна не заменяют визуальный заезд в Forward+: объёмный туман,
яркость и качество теней нужно оценивать с рабочим графическим рендерером.
