# Rally — Mitsubishi Lancer Evolution (Godot 4.x)

Раллийный спецучасток с ручной разметкой: одна трасса, один ресурс, никакой
скрытой генерации. Трасса целиком описана в `data/tracks/stage_forest.tres` —
осевая линия (Curve3D), рельеф вокруг неё и список ассетов. Всё это
редактируется в инспекторе Godot, без единой строчки кода.

```
data/tracks/stage_forest.tres        ← весь спецучасток (открывать в инспекторе)
data/tracks/stage_forest_route.tres  ← осевая линия дороги (Curve3D)
data/props/*.tres                    ← ассеты: ели, валуны, кусты, щиты
scenes/props/*.tscn                  ← готовые «многосоставные» объекты
data/setups/*.tres                   ← четыре конфигурации машины
scripts/rally_stage.gd               ← «запекание» карты из ресурсов
scripts/road_network.gd              ← расстояние до дороги / километраж
tools/author_route.py                ← генератор осевой линии (по желанию)
```

## Быстрый старт

1. Открыть `project.godot` в Godot 4.4+ (проверялось на 4.4 API).
2. **F5** — меню. Дождаться первого импорта.
3. Выбрать конфигурацию машины → **СТАРТ**.
4. **F6** на `scenes/rally_stage.tscn` — тот же заезд без меню.

### Управление

| Клавиши | Действие |
|---|---|
| W / S, ↑ / ↓ | газ / тормоз-задний ход |
| A / D, ← / → | руль |
| Space | ручник |
| Q / E | КПП в ручном режиме |
| C | камера: action-3rd → капот → кокпит |
| V | привод AWD → RWD → FWD |
| R | сброс машины на старт |
| ESC | пауза |

## 1. Как устроена трасса

Карта не генерируется «на лету» и не зависит от сида. Есть **осевая линия**
(сплайн из точек) и **функция высоты**, которая достраивает землю вокруг неё:

```
высота = база + (высота_дороги - база) * (1 - t)
```

* `t = 0` на полотне → земля ровно совпадает с дорогой;
* `t = 1` вдали → чистый рельеф;
* между ними — насыпь/выемка, уклон которой не круче
  `embankment_slope_deg`.

Поэтому дорога **не может** пробить рельеф и на ней не бывает «кочек под
большим углом»: и меш полотна, и меш земли, и все ассеты берут высоту из
одной функции.

База рельефа складывается из:

* **регионального уровня** — высота дороги, размытая на десятки метров
  (поэтому дорога всегда лежит в своём рельефе, а не на 30-метровой насыпи);
* **холмов** (`hills_height`, `ridge_height`), которые включаются плавно по
  мере удаления от дороги (`hills_fade_start`, `hills_fade_length`);
* **лимита склонов** (`max_terrain_slope_deg`) — страховка: если где-то
  (например, между «ногами» тесной шпильки) получается стенка, она
  размазывается на несколько ячеек сетки;
* **кювета** (`road_ditch_depth`, по умолчанию 0.6 м) — земля у самой кромки
  намеренно опущена. Полотно всегда лежит выше земли, а его внешняя кромка
  ложится ровно на меш земли, поэтому между дорогой и рельефом нет ни щели,
  ни «протыкания» даже на косогоре.

### Как редактировать дорогу

Три равнозначных способа — все правят один и тот же Curve3D:

1. **В 3D-вьюпорте.** Открыть `scenes/rally_stage.tscn`, выбрать узел
   `Route` (Path3D) → **Curve3D** → кнопка редактирования точек. Тянуть
   точки мышью; высота точки — это высота дороги.
2. **В инспекторе.** Открыть `data/tracks/stage_forest_route.tres`,
   раскрыть `Points` и менять координаты.
3. **Скриптом.** `tools/author_route.py` собирает кривую из отрезков
   («прямая/дуга + подъём»), сглаживает профиль и пишет `.tres`:
   ```
   python3 tools/author_route.py
   ```
   В нём же таблица `SEGS` — самый быстрый способ перепробовать компоновку.

После правки — кнопка **«Пересобрать трассу»** в инспекторе корневого узла
`RallyStage` (скрипт помечен `@tool`, поэтому трасса видна в редакторе сразу).

**Правило, которое экономит нервы:** делайте шпильки на «полках» — 30–50 м
ровной дороги до и после разворота. Тогда две ветки шпильки оказываются на
одной высоте и между ними не нужно строить стенку.

### Скорость и качество

* `terrain_cell` — шаг сетки земли. `2.0` — красиво, `3.0` — грубее и
  быстрее (время сборки карты растёт квадратично).
* `terrain_margin` — сколько метров земли вокруг трассы. Больше — дольше.
* `road_step` — шаг полотна. `1.0–1.5` достаточно.

## 2. Как расставить ассеты

### Автоматически (списком)

1. Создать ресурс: **ПКМ в FileSystem → Создать → Ресурс → `RallyProp`**.
2. Заполнить:
   * `mesh` — любой меш (дерево, камень, столбик) **или** `scene` — готовая
     сцена (`scenes/props/pine_tree.tscn`, `road_sign.tscn`);
   * `mode`:
     * `ALONG_ROAD` — объекты вдоль обочины с шагом `spacing`
       (деревья у дороги, кусты, щиты);
     * `SCATTER` — «посев» по всей карте с отступом `road_clearance`
       (валуны, дальний лес);
   * `lateral_min/max` — насколько далеко от края полотна ставить;
   * `side` — слева / справа / с двух сторон;
   * `count` — сколько штук (`0` = посчитать по шагу);
   * `scale_min/max`, `scale_y`, `random_yaw`, `align_to_slope`,
     `face_road` + `face_road_offset_deg` (для щитов и столбиков);
   * `collision` — обернуть объект в `StaticBody3D` с цилиндром
     (`collision_radius`, `collision_height`).
3. Перетащить ресурс в массив **`props`** трассы
   (`data/tracks/stage_forest.tres`).
4. «Пересобрать трассу» — или просто запустить заезд.

Готовые примеры: `prop_pine_near.tres` (ель из сцены, с коллизией),
`prop_fir_forest.tres` (дальний лес, `MultiMesh` — один draw call),
`prop_boulder.tres`, `prop_bush.tres`, `prop_warning_sign.tres`.

> Объекты без коллизии и без сцены ставятся через `MultiMesh` — сотни
> деревьев почти ничего не стоят по производительности. Объекты со сценой
> или коллизией — обычные узлы.

### Руками (поштучно)

Положите свои `Node3D`/`MeshInstance3D` в узел **`ManualProps`** сцены
`rally_stage.tscn` — генератор этот узел не трогает. Удобно для «постановочных»
объектов: стартовая арка, дом, брод, забор.

### Чего генератор не делает

Он не расставляет деревья по своему вкусу: что лежит в `props`, то и будет на
трассе. Убрали ресурс из массива — объекты исчезли.

## 3. Параметры трассы (`data/tracks/stage_forest.tres`)

| Группа | Поля |
|---|---|
| Описание | `id`, `display_name`, `description`, `surface_name`, `difficulty`, `target_time` |
| Дорога | `road_curve`, `road_half_width`, `road_shoulder`, `road_step`, `road_camber`, `offroad_grip` |
| Рельеф | `terrain_margin`, `terrain_cell`, `terrain_seed`, `hills_height/frequency`, `ridge_height/frequency`, `hills_fade_start/length`, `max_terrain_slope_deg`, `road_ditch_depth`, `detail_height/frequency`, `embankment_slope_deg`, `embankment_min/max_width` |
| Неровности полотна | `bumps_amplitude`, `bumps_wavelength`, `bumps_roughness`, `bumps_cross` |
| Ассеты | `props`, `spawn_route_markers`, `spawn_edge_posts`, `checkpoint_interval` |
| Цвета | `ground_color`, `ground_color_2`, `rock_color`, `road_color`, `road_color_2`, `shoulder_color`, `edge_post_color` |
| Небо и свет | `sky_top_color`, `sky_horizon_color`, `fog_color`, `fog_near`, `fog_far`, `sun_energy`, `sun_pitch`, `sun_yaw` |
| Сцепление | `grip_scale`, `rolling_resistance_scale` |
| PS1-стиль | `ps1_style`, `flat_shading`, `dither_fog`, `color_banding`, `sky_flat`, `enable_speed_fx` |

**Неровности полотна** (`bumps_*`) — это то, что чувствует машина: волны
(«стиральная доска») и мелкая тряска. Амплитуда 0.1–0.2 м уже ощутимо трясёт
на 80 км/ч; больше 0.3 — уже «трамплин».

---

## 4. Вторая трасса

1. Скопировать `stage_forest.tres` → `stage_my.tres`, поменять `id`,
   `display_name`, цвета, рельеф.
2. Скопировать `stage_forest_route.tres` → `stage_my_route.tres` и
   перетащить новый Curve3D в поле `road_curve`.
3. Добавить ресурс в массив `tracks` в `data/rally_game_config.tres`.
4. Кнопка в меню появится сама.

## 5. Что изменилось относительно старой версии

* Удалена процедурная генерация маршрута (`rally_route.gd`) и «случайные
  трассы» вместе с сидами — вместо них ручная осевая линия.
* Удалены трассы-заготовки `track_01…track_07`, сцены под них, полигон и
  слалом, шейдер плоскостного полигона.
* Дорога и земля больше не считаются «каждый сам по себе»: одна функция
  высоты, поэтому полотно не клипает через рельеф.
* Появились `RoadNetwork` (расстояние/километраж по дороге), `RallyProp`
  (ассеты), `@tool`-предпросмотр трассы в редакторе.
* Мини-карта в меню рисует ту же кривую, что и заезд.

## 6. Если что-то не так

| Симптом | Причина / лечение |
|---|---|
| В редакторе пусто | нажать «Пересобрать трассу»; проверить, что у трассы заполнен `road_curve` |
| Дорога «висит» над землёй | слишком большой `embankment_max_width` при маленьком `embankment_slope_deg` |
| Дорога местами «утоплена»/клипает | `road_ditch_depth` должен быть > 0 (0.6 по умолчанию); если стоит 0 — вернуть |
| Провалы/стенки между ветками шпильки | сделать «полку» (ровный участок) до и после шпильки, либо уменьшить `max_terrain_slope_deg` |
| Долго грузится | увеличить `terrain_cell` (3.0) и уменьшить `terrain_margin` |
| Машина проваливается на старте | проверить, что у сцены есть узлы `Terrain/TerrainMesh`, `Terrain/TerrainCollider` |
| Нет рекордов | `user://rally_records.cfg`, ключ — `id` трассы |

Документация по машине и подвеске — `RALLY_SETUP_RU.md`.
