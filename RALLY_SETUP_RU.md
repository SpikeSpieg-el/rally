# Настройка Mitsubishi Lancer Evo (GEVP)

Раньше параметры машины были зашиты в `scripts/rally_car.gd::_configure_gevp()`.
Теперь **всё настраивается в инспекторе Godot**: откройте любой файл из
`data/setups/` и меняйте `@export`-поля. Код лишь применяет выбранный ресурс
до инициализации GEVP.

## Четыре готовые конфигурации

| Файл | Название | Идея |
|---|---|---|
| `data/setups/setup_01_gravel.tres` | ГРАВИЙ | длинноходная подвеска, AWD 38:62, базовый момент 390 Н·м |
| `data/setups/setup_02_tarmac.tres` | АСФАЛЬТ | низкая, жёсткая, COF ×1.28, момент 420 Н·м |
| `data/setups/setup_03_snow.tres` | ЗИМА | мягкая, момент 300 Н·м, ранний traction control |
| `data/setups/setup_04_group_a.tres` | GROUP A | 520 Н·м, широкие шины, жёсткие стабилизаторы |

Конфигурация выбирается **в меню перед стартом**. Также её можно назначить
 напрямую в Inspector узла `RallyCar` (`setup_override`) или сцены
`RallyStage` (`car_setup_override`) — удобно при запуске сцены через F6.

## Группы параметров ресурса

| Группа | Поля | Комментарий |
|---|---|---|
| Мотор | `max_torque`, `max_rpm`, `final_drive`, `gear_ratios`, `torque_curve`, `traction_control_max_slip` | кривая момента необязательна; без неё используется базовая из `rally_car.gd` |
| Привод | `drivetrain` (AWD/RWD/FWD), `awd_front_torque` | `0.38` = 38 % момента на переднюю ось |
| Масса | `vehicle_mass`, `front_weight_distribution`, `center_of_gravity_height_offset` | ЦТ рассчитывается GEVP по точкам колёс; отрицательное значение опускает его |
| Подвеска | `front/rear_spring_length`, `resting_ratio`, `damping_ratio`, `arb_ratio`, `bump/rebound_damp_multiplier` | см. ниже |
| Шины | `tire_radius`, `tire_width`, `grip_scale`, `tire_stiffness_scale`, `rolling_resistance_scale` | `tire_radius` автоматически масштабирует 3D-модель колеса |
| Камера | `chase_distance`, `chase_height` | остальные параметры камеры — в Inspector `RallyCar` |
| Визуал | `body_color`, `accent_color` | оттенок ливреи; `Color(1,1,1,1)` = оригинальная текстура |

Координаты машины: **+Z — вперёд, +Y — вверх, +X — влево**. Единицы — метры,
килограммы, секунды, ньютоны, радианы.

## Сцепление: три уровня множителей

1. Базовые словари в `scripts/rally_car.gd` (`BASE_COF`, `BASE_STIFFNESS`,
   `BASE_ROLLING`, …): `Road 1.50`, `Dirt 1.00`, `Grass 0.65`.
2. `RallyCarSetup.grip_scale` и `rolling_resistance_scale` — характер машины.
3. `RallyTrackConfig.grip_scale` и `rolling_resistance_scale` — покрытие трассы
   (асфальт `1.35`, гравий `1.0`, снег `0.58` и т.д.).

Итоговое значение = база × машина × трасса. Меняйте трассу и конфигурацию
независимо: одно и то же зимнее сетап-решение можно проверить на пяти картах.

## Подвеска: как настраивать

- `spring_length` — доступный **ход**, а не жёсткость. Разумно `0.22–0.36 м`.
- `resting_ratio` — доля хода, сжатая в статике. Больше → мягче пружина и ниже
  кузов. Ориентир `0.50–0.60`, меняйте шагом `0.02`.
- `damping_ratio` — общее демпфирование. Шаг `0.03–0.05`.
- `bump_damp_multiplier` / `rebound_damp_multiplier` — сжатие и отбой. Обычно
  rebound заметно больше bump.
- `arb_ratio` — стабилизатор. Больше передний → недостаточная поворачиваемость,
  больше задний → избыточная. Для леса начинайте с `0.10–0.20`.

Смотрите `ХОД ПОДВЕСКИ` в HUD: ~55 % — статика, 65–85 % — работа, 100 % —
пробой. Для проверки используйте трассу **ЛЕС: ПОДВЕСКА** (F3) на 20–30 км/ч.

## Радиус колеса — важно

У импортированной модели Lancer Evo радиус **0.438 м**. Физический
`tire_radius` выставлен таким же, а `RallyCar.wheel_visual_radius` говорит
скрипту, во сколько раз масштабировать визуал, если вы поменяете радиус в
ресурсе. Если поставите свою модель с другим радиусом — поправьте оба поля и
точки крепления `Wheel_FL/FR/RL/RR` в `scenes/rally_car.tscn`:

```
точка крепления Y = tire_radius + spring_length × (1 − resting_ratio)
центр колеса в покое = tire_radius
```

## Порядок настройки без хаоса

1. **ПОЛИГОН** (F4): масса, развесовка, ЦТ, радиус, четыре контакта.
2. **ПОЛИГОН**: сравнение FWD/RWD/AWD при одинаковом газе (клавиша V).
3. **ЛЕС: ПОДВЕСКА** (F3): ходы, bump/rebound, ARB, отрывы колёс.
4. **ЛЕСНОЕ РАЛЛИ** (F1): баланс на скорости, дифференциалы, TCS.
5. Только после этого увеличивайте момент или уменьшайте сцепление.

Меняйте **одну группу за проход** и записывайте результат.

## Быстрая диагностика

| Симптом | Что проверить |
|---|---|
| Нет крена, «рельсы» | слишком низкий ЦТ, жёсткие ARB, `enable_stability` |
| Качает как лодку | мало damping, мягкий `resting_ratio`, слабые ARB |
| Частый bump-stop | мало хода/bump, высокая скорость на волнах |
| Oторвалось внутреннее колесо | жёсткий ARB или чрезмерное демпфирование |
| FWD буксует | момент, TCS, блокировка переднего дифференциала |
| Не входит в поворот | передний ARB, передняя шина, развесовка |
| Резкий занос | задний ARB, задняя шина, высокий ЦТ, момент на RWD |
| Колёса тонут/парят | `tire_radius` не совпадает с `wheel_visual_radius` |

GEVP — raycast-модель, а не полноценная multibody-симуляция рычагов. Цель —
честные нагрузки, ходы и сцепление без скрытого «приклеивания» машины к дороге.
